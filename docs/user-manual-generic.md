# Intranet User Manual (Generic Version)

This manual explains how to use a typical low-cost organizational intranet similar to the one i implemented for Girls’ Power Initiative (GPI) Calabar in 2017/2018.

## Introduction

The intranet provides the following services:

- Centralized file storage and sharing (Cloud Backup)
- Human Resource (HR) self-service portal
- Internal email for staff communication (works without internet)
- Digital library system

All services are accessible from the local office network.

## How to Access the Intranet

1. Connect to the office Wi-Fi (`wifi-name`)
2. Open any web browser (Chrome, Firefox, Edge, etc.)
3. Type the following address: `http://192.168.x.xx`
4. Bookmark this address for easy access

You will see links/tabs for: **Cloud Storage**, **HR System**, **Email**, and **Library**.

## 1. Cloud Storage / File Sharing

- Click on **Cloud Backup** or **Files**
- Login with your username and password (provided by ICT Officer)
- **To upload files**: Click the **+** or **Upload** button
- **To create folders**: Use the New Folder option to organize documents
- **To share a file/folder**: Click the Share button next to the item and select users

**Tip**: All official documents should be saved here instead of personal laptops.

## 2. Human Resource (HR) System

- Click on **HR System**
- Login with your credentials
- Main sections usually include:
  - **My Info**: Update personal details, contacts, qualifications, etc.
  - **Leave**: Apply for annual leave or other types of leave
  - **Directory**: View list of all staff and volunteers
  - **Performance**: Staff appraisal (when activated)

**Important**: Always keep your personal and employment information up to date.

## 3. Internal Email

- Click on **Email**
- Login with your username and password
- This email works **entirely on the local network** — no internet required
- Use it to send internal memos, reports, and follow-ups between staff
- You can view Inbox, Sent, and Drafts

## 4. Library System

- Click on **Library**
- Login with credentials provided by the Librarian or ICT Officer
- Search and manage digital resources and track physical books

## Getting Help

- For login issues or technical problems → Contact the **ICT Officer**
- For content or usage questions → Contact your supervisor or Librarian
- We welcome feedback to improve the system
