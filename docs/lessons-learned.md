# Lessons Learned: GPI Intranet Project

## Overview
This document captures key insights, challenges, and recommendations from the implementation of the GPI intranet system.

---

## Challenges Faced

### 1. Funding Delays
- Delayed procurement of equipment

### 2. Hardware Limitations
- Dependence on refurbished systems

### 3. Time Constraints
- Limited time for full deployment and training

### 4. User Adoption
- Resistance to moving from manual to digital systems

---

## Key Lessons

### 1. Design Before Implementation
A clear architecture reduces future issues.

---

### 2. Security Must Be Built-In
Not added later.

---

### 3. Training is Critical
User adoption determines project success.

---

### 4. Documentation Matters
Improves maintainability and scalability.

---

### 5. Open-Source is Powerful
Enterprise-level systems can be built at low cost.

---

## What I Would Do Differently Today

- Use virtualization (Proxmox)
- Deploy cloud backup (Azure/AWS)
- Implement monitoring tools (SIEM)
- Add Zero Trust security model

---

## Key Takeaway

With the right approach, **low-cost infrastructure can deliver enterprise-grade results**, especially in resource-constrained environments.
